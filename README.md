# Desarrollo de aplicaciones móviles para Sistemas Operativos Android Nivel Avanzado

## Plataforma de laboratorios

Te damos la bienvenida a la plataforma de laboratorios del curso Desarrollo de aplicaciones móviles para Sistemas Operativos Android Nivel Avanzado. Aquí aplicarás Kotlin, concurrencia, Jetpack Compose, arquitectura, servicios REST, persistencia y geolocalización mediante prácticas guiadas. El recorrido culmina con una aplicación de consulta de eventos sísmicos.

## Lista de laboratorios

Haz clic en el título de cada laboratorio para abrir su guía. Realiza las prácticas en el orden indicado y verifica los requisitos de continuidad de cada proyecto.

## Capítulo 1: Kotlin Multiplataforma (KMP) avanzado y Corrutinas

### [Laboratorio 1.1 Configuración del proyecto y desarrollo de concurrencia con Kotlin](Capitulo01/README.md)

- Descripción: Configura el proyecto Android y desarrolla un motor de simulación de telemetría con Kotlin. Aplica clases de valor, delegación, contratos, corrutinas, StateFlow y SharedFlow, y verifica la concurrencia, la cancelación y las emisiones mediante pruebas unitarias.
- ⏱️ Duración estimada: 200 min.

## Capítulo 2: Interfaces modernas con Jetpack Compose

### [Laboratorio 2.1 Construcción de interfaz declarativa con Jetpack Compose](Capitulo02/README.md)

- Descripción: Construye la interfaz de telemetría con Jetpack Compose y Material Design. Implementa listas con LazyColumn, navegación tipada, pantallas de detalle y gestión del estado con State Hoisting, remember y rememberSaveable.
- ⏱️ Duración estimada: 360 min.

## Capítulo 3: Arquitectura y buenas prácticas (MVVM + Clean Architecture)

### [Laboratorio 3.1 Arquitectura MVVM + Clean Architecture](Capitulo03/README.md)

- Descripción: Reestructura TelemetryTracker mediante MVVM y Clean Architecture, separando dominio, datos y presentación. Integra repositorios, casos de uso, ViewModel, StateFlow, SharedFlow e inyección de dependencias con Hilt, conservando los componentes de las prácticas anteriores.
- ⏱️ Duración estimada: 248 min.

## Capítulo 4: Networking y consumo de APIs REST

### [Laboratorio 4.1. Integración de API REST](Capitulo04/README.md)

- Descripción: Integra Retrofit, OkHttp y Kotlinx Serialization para consultar y enviar telemetría a una API REST local en Python. Gestiona autenticación Bearer, transformación de datos, estados de pantalla y errores de red mediante Hilt, corrutinas y StateFlow.
- ⏱️ Duración estimada: 255 min.

## Capítulo 5: Persistencia avanzada (Room / DataStore)

### [Laboratorio 5.1. Persistencia avanzada con Room y DataStore](Capitulo05/README.md)

- Descripción: Agrega persistencia con Room y preferencias con DataStore. Implementa lectura offline-first y actualización manual desde la API, conserva datos ante fallos de conectividad y verifica migraciones de la base de datos y pruebas de persistencia.
- ⏱️ Duración estimada: 169 min.

## Capítulo 6: Geolocalización y servicios del dispositivo

### [Laboratorio 6.1. Geolocalización, mapas y acelerómetro](Capitulo06/README.md)

- Descripción: Incorpora una pantalla de geolocalización que gestione permisos, obtenga ubicaciones y dibuje una trayectoria en Google Maps Compose. Utiliza el acelerómetro para recentrar la cámara, calcula la distancia aproximada y prueba el comportamiento de captura y cancelación con la actividad visible.
- ⏱️ Duración estimada: 150 min.

## Capítulo 7: Proyecto final integrador

### [Laboratorio Final: Aplicación Android para consultar eventos sísmicos, guardar favoritos y calcular su distancia aproximada](Capitulo07/README.md)

- Descripción: Desarrolla una aplicación para consultar eventos sísmicos de USGS, filtrar por magnitud, mostrar detalles y guardar favoritos para consultarlos sin conexión. Integra Compose, MVVM, Retrofit, Room, Flows y ubicación para calcular la distancia aproximada al epicentro, y utiliza asistencia de IA para revisar código, documentación y pruebas.
- ⏱️ Duración estimada: 135 min.
